# Release limitations

This anonymous release provides CPU verification of frozen panels, saved pointwise predictions, metric tables, paired bootstrap intervals, and figure artwork. Frozen functional identifiers required for schema/sampler compatibility (`ppi_shift`, `ppi_shift_release`, `ppi-shift-release`, `ppi_shift.e001_negative_environment.v1` through `.v3`, `ppi_shift_anchor_v1`, `ppi_shift.e005_core4_1024.v1`, `ppi_shift.dscript_esm2_150m_contact_cnn.v1`) remain present and are documented as residual functional strings rather than silently broken.

All 44 pair files retain exact original compressed bytes, row order, identifiers, labels, and multiplicity. The 432 corrected 512 replay cells (`E003_corrected_replay`) use probability clipping `[1e-7, 1 - 1e-7]` and are distinct from historical original 512 table metrics. The 432 primary unshuffled 1024 cells (`E005_core`) are kept strictly separate from the 432 broken-pair partner-shuffled 1024 control cells (`E005_primary`). Both the 72 Fully Random Gold cells (`results/fully_random_pointwise/`) and the 24 Fully Random external cells (`results/fully_random_external_pointwise/`) use `E005_core`; both Fully Random training and validation negatives changed together, affecting checkpoint selection.

Historical `E003` per-row validation predictions (72 units) were never saved historically on the cluster, so validation-threshold optimization is only re-executed per-row on all 72 `E005_core` units (`results/validation_pointwise/E005_core/`), while E003 thresholded test evaluations (`reported_mcc.csv`) are verified against the recorded scalar thresholds (`validation_selected_thresholds_144_units.csv`). Also omitted from distribution: all 114 checkpoint `.pt` binaries (`manifests/CHECKPOINT_INVENTORY.csv` inventory only), PLM/embedding caches, unsplit redundant ~1.6 GB cluster shuffle text dumps (already represented by all 432 split `E005_primary` `.csv.gz` files), full 50,398-protein `sequence_registry.csv` (17,981 release-panel sequences included), and third-party rights-blocked source database dumps. No end-to-end training or GPU inference reproduction is claimed.

Exact-sequence absence and resolved-protein novelty use explicitly stated Gold train-only or train+validation reference sets, and establish neither family disjointness nor OOD. Assay non-detections (Y2H-iso), curated experimental negatives (IntAct), and synthetic unobserved pairs have distinct meanings. HuRI zero collisions cover only 185,737/560,382 screenable pairs (33.14%). Homology filtering was selective, not a full new benchmark. Three seeds describe optimization variation; fixed-pair bootstrap intervals do not measure retraining uncertainty.

All 22 PDFs referenced in the final manuscript live in `figures/R2/` (18 metadata-sanitized R2 PDFs with zero-pixel-diff at 144 dpi plus 4 final-manuscript PDFs supplied verbatim), alongside 3 superseded historical R2 PDFs marked `status=historical` in `manifests/R2_FIGURES.csv`. Supported redraws write to `results/figures_regenerated/`. Main Figure 5's `logistic(sum+absdiff)` (formerly R2 Figure 6; redrawn by `scripts/plot_figure6.py`) is pair-dependent; `Additive(sum only)` has one deterministic fit per construction.
