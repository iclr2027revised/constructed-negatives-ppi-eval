# Protocol and reusable procedures

The experiment compares negative environments with the same eligible Gold positive backbone. Canonical sequences remove whitespace and uppercase residues. Eligible training sequences are filtered before candidate-universe construction; raw sequences are not cropped. The four anchor-preserving methods use a deterministic fixed endpoint and choose its partner by Uniform, degree, sequence-nuisance or frozen-ESM matching. Global Bernett ILP and TPPNI are separately identified constructions; Fully Random samples both endpoints. Unobserved negatives remain unknown biologically.

`src/ppi_shift/negatives.py` supplies data contracts, deterministic anchor orientation, candidate eligibility and the four original matching samplers. `e003_method_fidelity.py` supplies the global ILP and exact logistic-SCM/L3 TPPNI implementation; `rebuttal_random_pair.py` supplies the two-endpoint Fully Random sampler. `e002_negative.py` retains the earlier adaptation for comparison, **not** as a replacement for E003. These are recovered current author modules with local dependencies, not a byte-identical claim about historical dirty executions. NumPy is required; ILP uses SciPy/HiGHS. Missing frozen ESM features, GO annotations and stage registries prevent a guaranteed historical panel rebuild. The exact panels are distributed instead. Do not run large candidate enumeration locally.

Training and validation use their separately named exclusion registries; evaluation-positive-union is not substituted for either. The historical exact TPPNI configuration explicitly uses the complete frozen positive topology before split; the stage-visible leakage-safe variant is separate. This is a disclosed historical design limitation, not a prospective test-label firewall claim for that topology. Test metrics/labels must not be used to tune any new fit, threshold, sampler or checkpoint.

The config snapshots are reference records with historical fields; they are not launchable training pipelines. The executed D-SCRIPT adapter used frozen ESM2-150M/640-dimensional inputs. RAPPPID executed with 64 hidden units per direction, despite the older 32-unit text in the configuration snapshot. TUnA was adapted and is not claimed identical to its publication. SENSE-PPI lacked its faithful ESM2-3B cache; it was not rejected for poor performance.

Checkpoint selection maximizes matched-validation AUPRC. Available MCC thresholds are validation-owned. `scripts/evaluate_predictions.py` joins prediction row IDs to frozen panels, rejects partial/duplicate/nonfinite scores and evaluates saved scores on CPU. `reproduce.py --all` compares them with frozen metric values. E003 replay uses the recorded clipped-probability convention, E005 primary raw probability. Corrected shuffling uses the sequence actually associated with the shuffled partner, avoiding the withdrawn stale-ID alias behavior; all 432 E003 corrected 512 shuffled prediction columns (`results/shuffle_pointwise/`) and all 432 `E005_primary` broken-pair partner-shuffled prediction files (`results/pointwise/E005_primary/`) are included alongside the shuffle summaries.

For new evaluations, produce a CSV with `row_id,score` for the entire selected panel, then use `python scripts/evaluate_predictions.py --help`. For exact saved-result verification use README commands. Acquisition is separate from evaluation; current downloads are not relabeled as historical frozen inputs.

Use `data/mappings/vidal_orf_crosswalk.csv` as an inspectable identity mapping. Only `resolved` or `ambiguous` identities backed by the frozen registry are eligible for novelty assignment. `accession_not_in_registry` remains unresolved. A known overlap on either endpoint establishes at-least-one overlap even when the other endpoint is unresolved. Sequence-first strata and crosswalk-only summaries have different coverage and must not be mixed.

YAML serialization helpers require `PyYAML==6.0.3` in addition to the pinned numerical dependencies. YAML configurations remain descriptive snapshots; installing this parser does not restore the missing historical training pipeline.
